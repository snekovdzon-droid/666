# MANY DEAD — восстановление последней версии

Источник истины: HTML `zombie-voxel.html`, переданный автором 29 октября 2026 года. SHA-256: `2175f6e78b87a700afd7e4145725cb767a4ed702494cfdb1fbc393a751903675`.

Создана отдельная ветка `migration/latest-html-v0-80` от `claude/game-claude-code-ixgsch`; исходная ветка не изменена.

Подготовлен архив `MANY_DEAD_latest_source_migration.zip` в разговоре с автором. Архив содержит `index.html` и 53 восстановленных JavaScript-файла (`vendor`, `assets`, `src`). При обратной подстановке JS в HTML получается исходный файл без текстовых отличий. Все 53 JS-файла прошли `node --check`.

Перенос архива в рабочую копию, проверка браузерных тестов и commit/push остаются следующими действиями. Не объединять без проверки в браузере. Дополнительные блоки включают ресурсы зомби, ресурсы меню, выбор класса, миниатюры карт, изображения оружия и новое главное меню. В исходной версии HTML карта «Кладбище» находится в позиции `src/04d_map_city.js`, поэтому имя файла пока сохранено.

Порядок для локального переноса: `git fetch origin`, `git switch migration/latest-html-v0-80`, распаковать архив в корень проекта, `node tools/smoke.js index.html`, `node tools/play.js index.html`, затем `git add index.html src assets vendor`, commit и push после проверки.
